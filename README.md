# Тестове завдання — Список користувачів

## Опис

Проєкт реалізує сторінку користувачів з:

- Відображенням **ім’я**, **email** та **місто**
- Клієнтським **пошуком та фільтром за містом**
- Inline **редагуванням користувача**

Розроблено з використанням **Next.js 13**, **React 18**, **TypeScript**.  
Візуальний дизайн не є пріоритетом — оцінюється структура коду, типізація і логіка.

---

## Технології

- Next.js 13 (App Router)
- React 18
- TypeScript
- CSS Modules

---

## Використання

### Фільтрація користувачів:

- Введіть текст у пошукове поле для фільтрації по імені
- Виберіть місто у випадаючому списку для фільтрації по місту

### Редагування користувачів:

- Натисніть Edit у карточці користувача
- Змініть ім’я, email або місто
- Email проходить валідацію, у разі помилки з’явиться повідомлення
- Натисніть Save, щоб оновити дані локально
